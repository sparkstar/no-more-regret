# 개발용 기능

[English](DEBUG_FEATURES.md) | 한국어

포트를 고치고 시험할 때 쓰는 기능입니다. 되감기, 상태 저장, 빨리 감기, 멈춤, 플레이의 녹화와 재생, 재생 화면의 캡처가 있습니다.

## 켜기

- 기본으로 꺼져 있습니다. 명령줄에 `--debug-feature`를 주거나, 게임 폴더의 `enhanced.cfg`에 `debug_feature=true`를 적으면
  켜집니다. 실행을 시작할 때 정해지고 그 실행 내내 그대로입니다.
- 끈 채로 아래 명령줄 옵션을 주면 실행하지 않고 끝냅니다. 아래 키는 게임에 그대로 갑니다.
- 켜면 아래 키들이 키 설정 화면에도 나타나 바꿀 수 있습니다. 기능이 동작하는 동안에는 창 왼쪽 위에 그 상태와 프레임 번호를
  보여 줍니다.

## 키

| 키 | 하는 일 |
|---|---|
| F11(누르는 동안) | 되감기. 게임의 네 배 빠르기로 되돌리고, 키를 놓은 자리에서 이어 갑니다 |
| F12 / Shift+F12 | 상태 저장 / 불러오기. 메모리에 하나만 두며, 끝내면 사라집니다 |
| F6(누르는 동안) | 빨리 감기 |
| Pause | 멈춤과 풀기. 멈춘 동안 게임 시간이 가지 않습니다 |
| Ctrl+F11 | `--watch`로 보던 녹화를 그 자리에서 이어받아 직접 플레이합니다 |

## 녹화와 재생

녹화는 디렉터리 하나입니다. 프레임(1/60초)마다의 입력(`inputs.tsv`)과, 녹화를 시작할 때의 세이브와 설정 파일(`files/`)이
들어갑니다. 입력이 같으면 플레이도 같으므로, 녹화를 재생하면 그 플레이가 그대로 다시 돕니다. 재생은 `files/`의 복사본에 쓰기
때문에 게임 폴더의 세이브와 설정은 바뀌지 않습니다.

| 명령줄 옵션 | 하는 일 |
|---|---|
| `--record DIR` | 창으로 하는 플레이를 DIR에 녹화합니다. 녹화하는 동안 되감거나 상태를 불러오면 녹화도 그 자리로 돌아갑니다 |
| `--replay DIR` | 녹화를 창 없이 가장 빠르게 다시 돌립니다. 녹화할 때와 게임 상태가 달라지면 알려 줍니다 |
| `--watch` | `--replay`의 녹화를 창에서 제 속도로 보여 줍니다. 녹화가 끝나거나 Ctrl+F11로 이어받으면 직접 플레이합니다 |
| `--continue DIR` | 녹화를 끝까지 빨리 돌린 뒤 그 자리부터 직접 플레이합니다. `--record`와 함께 쓰면 이어서 녹화합니다 |
| `--capture FILE` | 재생하는 화면과 소리를 NUT 파일로 씁니다(640x480, 와이드 화면이면 더 넓게; 초당 60프레임, 44100Hz 스테레오). `-`는 표준 출력입니다 |
| `--from TIME` | `--watch`는 그 자리까지 빨리 돌린 뒤 보여 주고, `--capture`는 그 자리부터 씁니다 |
| `--to TIME` | 재생을 그 자리에서 끝냅니다. `--continue`는 그 자리에서 이어 갑니다 |
| `--keep-files DIR` | 재생이 끝날 때 그 재생이 쓴 파일(세이브 등)을 DIR에 복사해 둡니다 |

시간은 프레임 수나 `[h:]m:ss[.ss]`로 씁니다. `--record`와 `--replay`를 함께 쓰면 재생한 입력이 새 녹화가 되고, 이어받은
뒤에는 플레이어의 입력이 녹화됩니다.

```sh
./crusader-port --debug-feature --record ~/rec/run1
./crusader-port --debug-feature --replay ~/rec/run1 --watch --from 12:30
./crusader-port --debug-feature --replay ~/rec/run1 --capture - | ffmpeg -f nut -i - run1.mp4
```

녹화 여러 개를 한꺼번에 재생해 보관한 상태와 비교하는 도구는 `port/tools/replays.py`입니다
([`port/tools/README.md`](../port/tools/README.md), 영어).
